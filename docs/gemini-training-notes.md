# Gemini研修 注意事項メモ（講師向け）

Gemini研修の実施時に受講者へ案内すべき注意事項をまとめる。研修資料そのものではなく、講師が口頭説明・スライド反映するためのソースメモ。

## Google利用規約改定（2026年7月30日）とメディア保存設定

### 発端

X（Twitter）で2026年7月26日に投稿された注意喚起が拡散（1,300万表示超）:
https://x.com/shikabane_rui/status/2081264654811091261

「7/30のGoogle規約変更で、画像検索した給与明細や免許証がAI学習に使われるようになる」という趣旨。

### 事実関係（2026年7月時点で複数ソース確認済み）

- Google利用規約は**2026年7月30日に改定**される。Googleから事前通知メールが届いており、これ自体は本物。同意ボタンはなく、**7月30日以降もサービスを使い続けると自動的に同意**した扱いになる。
- 改定に関連して、検索サービスとのやり取りで使用した**メディア全般**（Googleレンズで撮影・アップロードした画像、音声検索の音声など）がアカウントのアクティビティとして保存対象になり、サービス改善等に利用され得ることが明文化される。
- 保存はユーザー側でオフにできる:
  **Googleアカウント →「データとプライバシー」→「マイ アクティビティ」→ 検索サービスの履歴 → メディアの保存をオフ**（または「3か月ごとに自動削除」等の自動削除設定）。

### 研修で受講者に伝えること

1. **演習前に設定確認を案内する。** 個人のGoogleアカウントで演習する受講者には、上記のメディア保存設定（オフまたは自動削除）を演習開始前に確認してもらう。
2. **個人情報を含む画像を演習で使わせない。** 給与明細・免許証・保険証・社内資料などをGoogleレンズやGeminiにアップロードしない。演習素材は必ずダミーデータを配布する。
3. **煽らず正確に伝える。** 元ツイートの「過去に画像検索したものがAI学習される」という表現はやや不正確。改定の主旨は「検索サービスで使ったメディアの保存と、サービス改善等への利用の明文化」であり、設定でオフにできる。事実ベースで淡々と案内する。
4. **法人アカウントは別扱い。** 顧客のGoogle Workspaceアカウントは管理者ポリシーと法人向け規約でデータの取り扱いが異なる。支援先環境で演習する場合は、事前に情シス・管理者へデータ取り扱いポリシーを確認する。
5. **便乗フィッシングに注意。** 規約変更の正規通知メールは個人情報・カード情報の入力を求めない。入力を求めるメールは詐欺なので開かないよう一言添える。
