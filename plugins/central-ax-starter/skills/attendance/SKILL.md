# 勤怠打刻（attendance）

「出勤」「退勤」の一言で打刻を記録し、月末にそのまま提出できる勤怠CSVを作業フォルダに育てる。

## 原則

- **時刻は必ず実時刻を取る。** 記憶や会話の流れから推測せず、`date` コマンド（Windowsは `Get-Date`）で現在時刻を取得してから記録する
- **記録先は作業フォルダ内の `attendance/YYYY-MM.csv`。** CLAUDE.mdに別の記録先（パス・スプレッドシート等）が指定されていればそちらを優先する
- **既存行は書き換えない。** 打刻の訂正はユーザーが明示的に依頼したときのみ行い、訂正した旨をnote列に残す
- **二重打刻は黙って上書きしない。** 当日すでに同種の打刻がある場合は、既存の記録を示して追記・訂正・取消のどれにするか確認する
- CSVの列定義・記録例・集計ルールは `references/attendance-guide.md` を読む

## フロー

### 出勤

1. 現在時刻を取得する
2. 当月のCSVが無ければヘッダー付きで作成する（`attendance/` フォルダも同様）
3. 当日行に出勤時刻を記録する
4. 「おはようございます。HH:MM 出勤で記録しました」と一言で報告する。当日が土日祝ならその旨も添える

### 退勤

1. 現在時刻を取得し、当日行に退勤時刻を記録する
2. 実働時間（退勤 − 出勤 − 休憩合計）を計算してwork_hours列に記録する
3. 「お疲れさまでした。HH:MM 退勤、本日の実働 X時間Y分です」と報告する
4. 出勤打刻が無い日の退勤は、出勤時刻をユーザーに確認してから両方記録する

### 休憩

「休憩入ります」で休憩開始、「戻りました」で休憩終了を記録し、休憩合計（分）をbreak_minutes列に積算する。

### 勤怠確認・月次集計

当月（または指定月）のCSVを読み、出勤日数・総実働時間・平均退勤時刻・打刻漏れ（出勤のみで退勤が無い日）を表で報告する。打刻漏れがあれば訂正するか確認する。
