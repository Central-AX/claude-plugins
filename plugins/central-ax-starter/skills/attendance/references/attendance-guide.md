# 勤怠記録ガイド（attendance references）

## 記録先

- 既定: 作業フォルダ直下の `attendance/YYYY-MM.csv`（月ごとに1ファイル）
- CLAUDE.mdに勤怠の記録先（別パス、スプレッドシート、勤怠SaaS等）が書かれていればそちらを優先する
- ファイル・フォルダが無ければ初回打刻時に作成する。文字コードはUTF-8（BOM無し）、改行はLF

## CSV列定義

```csv
date,day,clock_in,clock_out,break_minutes,work_hours,note
```

| 列 | 型・形式 | 説明 |
|----|---------|------|
| `date` | YYYY-MM-DD | 打刻日 |
| `day` | 月〜日 | 曜日（漢字1文字） |
| `clock_in` | HH:MM | 出勤時刻（24時間表記） |
| `clock_out` | HH:MM | 退勤時刻。日をまたいだら翌日側に丸めず `26:10` のような24時間超表記で当日行に記録する |
| `break_minutes` | 整数 | 休憩合計（分）。休憩打刻が無ければ空欄のまま |
| `work_hours` | H:MM | 実働時間 = clock_out − clock_in − break_minutes。退勤打刻時に計算して埋める |
| `note` | 自由記述 | 在宅/出社、直行直帰、訂正履歴（例: `出勤時刻を9:00→8:45に訂正(本人申告)`）など |

## 記録例

```csv
date,day,clock_in,clock_out,break_minutes,work_hours,note
2026-07-01,水,09:02,18:15,60,8:13,在宅
2026-07-02,木,08:45,19:30,60,9:45,出社
2026-07-03,金,09:10,,,,退勤打刻漏れ
```

## 休憩の積算

- 「休憩入ります」時点の時刻をnote列に仮記録（例: `休憩中(12:00-)`）し、「戻りました」でその差分（分）をbreak_minutesに加算して仮記録を消す
- 戻り打刻が無いまま退勤した場合は、休憩終了時刻を確認してから実働を計算する
- 休憩打刻を使わない運用（固定60分など）がCLAUDE.mdに書かれていれば、退勤時にその値を自動で入れる

## 月次集計の出力項目

「勤怠確認」「今月の勤怠」と言われたら当月CSVから以下を表で報告する:

- 出勤日数（clock_inがある日の数）
- 総実働時間・1日平均実働
- 平均出勤時刻・平均退勤時刻
- 打刻漏れ日の一覧（出勤のみ・退勤のみ・休憩戻り無し）
- 実働10時間超の日があれば注意として列挙

## エッジケース

| 状況 | 対応 |
|------|------|
| 当日すでに出勤打刻あり、再度「出勤」 | 既存時刻を見せて「そのまま／訂正／2回目の記録(中抜け)」を確認 |
| 出勤打刻が無い日の「退勤」 | 出勤時刻を確認してから両方記録 |
| 前日の退勤打刻漏れが残っている | 当日の出勤打刻は先に記録し、そのあと前日分をどうするか確認 |
| 過去日の打刻依頼（「昨日16時に退勤してた」） | 該当日の行に記録し、noteに `事後打刻` と残す |
| 月をまたいだ最初の打刻 | 新しい月のCSVを作成。前月に打刻漏れが残っていれば一言知らせる |
