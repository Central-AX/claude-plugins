# 税務成果物チェックリスト（C/W/S重大度制）

`tax-reviewer` が使う検査項目の完全版。事務所独自のチェック項目がある場合は追加してよい。

## C: 重大（1件で差し戻し）

| # | 項目 | 見るポイント |
|---|------|------------|
| C1 | 根拠が実在しない | 条文番号・項・号、通達番号が実在するか。原典（e-Gov法令検索・国税庁の法令解釈通達）で確認する |
| C2 | 根拠と内容が一致しない | 引用した条文・通達が、本文で述べている内容を本当に定めているか。要件・金額・割合・期限を突き合わせる |
| C3 | 計算誤り | 税額・所得・控除額・按分などを検算する。端数処理、税率、合計、転記ミス |
| C4 | 適用年度・改正前後の取り違え | 対象の年度・事業年度に適用される規定か。改正の施行日・経過措置を確認する |
| C5 | 前提事実の欠落 | 結論に必要な事実（法人/個人、資本金、期間、金額、届出の有無など）が無いまま結論を出していないか |
| C6 | 入力禁止情報の混入 | マイナンバー、預金口座番号・カード番号、パスワード・認証情報、病歴など要配慮個人情報が成果物に入っていないか |
| C7 | 別の顧問先の情報の混入 | 他の顧問先の名前・数字・事情が残っていないか |

## W: 注意（対応を推奨）

| # | 項目 | 見るポイント |
|---|------|------------|
| W1 | 断定しすぎ | 事実関係によって結論が変わるのに「できます」「該当します」と言い切っていないか |
| W2 | 要件の一部省略 | 特例・控除などの適用要件をすべて挙げているか。抜けている要件はないか |
| W3 | 例外規定・特例の未検討 | 例外、特例、別の選択肢（有利・不利の比較）を検討しているか |
| W4 | 手続・期限の漏れ | 届出・申請・添付書類・保存要件・期限の記載が必要なのに無くないか |
| W5 | 根拠が二次情報だけ | 解説記事やまとめサイトだけを根拠にしていないか。原典を示す |

## S: 表現・品質

| # | 項目 | 見るポイント |
|---|------|------------|
| S1 | 分かりやすさ | 顧問先向けなら専門用語に説明があるか。一文が長すぎないか |
| S2 | 構成 | 結論が先にあるか。根拠・確認事項・注意点が分かれているか |
| S3 | 表記 | 数字・単位・年度表記（令和/西暦）の統一、誤字 |

## 根拠の確認先

| 確認したいもの | 確認先 |
|----------------|--------|
| 法律・政令・省令の条文 | e-Gov法令検索 https://laws.e-gov.go.jp/ |
| 法令解釈通達 | 国税庁「法令解釈通達」 https://www.nta.go.jp/law/tsutatsu/menu.htm |
| 一般的な取扱い | 国税庁「タックスアンサー」 https://www.nta.go.jp/taxes/shiraberu/taxanswer/index2.htm |
| 個別の取扱い事例 | 国税庁「質疑応答事例」 https://www.nta.go.jp/law/shitsugi/01.htm |

- ページが取得できない、該当箇所が見つからない、対象年度の版か分からない場合は「未確認」と書く
- e-Gov法令検索は現在の条文を表示する。過去の年度の規定が問題になるときは、改正の経緯・施行日を確認し、確認できなければ「未確認（対象年度の条文を確認できず）」と書く
- 解説記事・書籍の要約は原典を探す手がかりにだけ使い、それだけで「確認済み」にしない
