# 税務成果物チェック（tax-output-check）

AIが作った税務の成果物を、税理士の最終確認の前に、作った本人とは別の目で検査する。

## 原則

- **AIは税理士の判断を代わりに行わない。** この検査は税理士の確認を助けるためのもの。最終判断と責任は税理士にある。検査結果が「問題なし」でも、税理士の確認を省略しない
- **書いた本人に採点させない。** 成果物をこの会話で作った場合は、必ず `tax-reviewer` サブエージェント（Agentツール、subagent_type: central-ax-zeirishi:tax-reviewer）に検査を任せる
- **根拠は原典で確かめる。** 条文・通達はe-Gov法令検索や国税庁サイトで確認する。確認できなかったものは「未確認」と書き、推測で「問題なし」にしない
- **C（重大）が1件でもあれば「差し戻し」と明言する。** そのまま顧問先に出したり申告に使ったりしない
- 検査項目の全体（C/W/S重大度別）は `references/checklist.md` を読む

## 手順

1. 入力を確認する（`input-check` の原則）
   - 成果物にマイナンバー・口座番号などの入力禁止情報が含まれていないかを先に見る。含まれていれば伏字にしてから検査に回し、その混入自体をC指摘として扱う
2. 検査に必要な情報を集める
   - 成果物そのもの（文章・表・計算）
   - 前提: 対象の税目、法人か個人か、対象の年度・事業年度（課税期間）、事実関係、元になった資料
   - 分からない前提は推測で補わず「未確認」として渡す
3. `tax-reviewer` に「成果物＋前提＋元資料」を渡して検査させる
4. 結果を報告する
   - 判定（税理士確認へ回してよい／差し戻し（Cあり）／条件付き（W対応を推奨））
   - 指摘一覧（[C/W/S+番号] 該当箇所 → 何が問題か → 直し方）
   - 根拠の確認表（確認済み／不一致／未確認）と検算結果
   - 末尾の税理士確認欄（確認者・日付・判断）
5. 修正はユーザーの指示があってから行う。修正したら、もう一度 `tax-reviewer` に通す
