# 仕訳候補CSVの仕様

## 列の定義

見出し行（この順番で出力する）:

```csv
日付,取引先,摘要,借方勘定科目,貸方勘定科目,金額(税込),税区分,インボイス登録番号,登録番号の形式チェック結果,要確認フラグ,要確認理由
```

| 列 | 書く内容 | 書き方 |
|----|---------|--------|
| 日付 | 取引日（領収書の日付、請求書の取引日・請求日） | `YYYY-MM-DD`。読み取れなければ空欄＋要確認 |
| 取引先 | 発行者の名称 | 書かれているとおり。顧問先の取引先名をマスキングする運用ならその記号 |
| 摘要 | 何に使ったか | 品目・用途を短く（例: コピー用紙、〇月分通信費） |
| 借方勘定科目 | 勘定科目の候補 | 事務所・顧問先の勘定科目一覧があればその名称に合わせる |
| 貸方勘定科目 | 支払方法に応じた科目の候補 | 現金／普通預金／未払金 など。支払方法が分からなければ要確認 |
| 金額(税込) | 税込金額 | 半角数字、カンマなし。税率ごとに行を分けた場合はその税率分の金額 |
| 税区分 | 消費税の区分の候補 | 例: 課税仕入10%／課税仕入8%（軽減）／非課税／不課税／対象外。名称は会計ソフトに合わせて読み替える |
| インボイス登録番号 | 書類に記載された番号 | `T` と13桁の数字。記載がなければ空欄 |
| 登録番号の形式チェック結果 | 形式の確認結果 | `形式OK`／`形式NG`（桁数・文字の誤り）／`記載なし` |
| 要確認フラグ | 人の確認が必要か | `要確認`／空欄 |
| 要確認理由 | なぜ確認が必要か | 複数あれば「／」で区切る |

値にカンマ・改行・ダブルクォートが含まれる場合は、その値をダブルクォートで囲む（中のダブルクォートは2つ重ねる）。

## インボイス登録番号の形式チェック

- 形式: 先頭が `T`（半角大文字）、続けて13桁の半角数字。全角・ハイフン・スペースが入っていたら除いたうえで判定し、元の表記が違った旨を要確認理由に書く
- 形式OKでも、実在する番号か・取引日時点で登録が有効かは分からない。必要に応じて国税庁「適格請求書発行事業者公表サイト」（https://www.invoice-kohyo.nta.go.jp/）で確認するよう案内する
- 記載がない場合は、税区分を決めつけず要確認にする（免税事業者等からの仕入れは経過措置の対象になりうるため、控除の扱いは取引時期の規定で担当者が判断する）

## 要確認フラグを立てる主な場面

| 場面 | 要確認理由の書き方の例 |
|------|----------------------|
| 金額・日付・取引先が読み取れない | 金額読取不可 |
| 登録番号の記載なし・形式NG | 登録番号なし／登録番号形式NG |
| 10%と軽減8%の品目が混在 | 税率混在（行を分割） |
| 合計と内訳が合わない | 合計不一致 |
| 飲食費（会議費か交際費か） | 飲食費の区分（人数・目的を確認） |
| 1点10万円以上の物品 | 資産計上の可能性 |
| 私的な支出に見えるもの | 事業関連性の確認 |
| 支払方法が分からない | 支払方法不明（貸方科目は仮） |
| 同じ日付・金額・取引先の書類が複数 | 重複の可能性 |
| 外貨・海外の取引 | 外貨／国外取引の扱い |

## 会計ソフトへの取込について

このCSVは確認用の共通形式で、そのまま会計ソフトに取り込めるとは限らない。取り込むときは、各ソフトの取込形式に合わせて列の名前・順番・値（勘定科目名・税区分名・日付形式）を合わせ直す必要がある。

下は列の対応の目安。正確な取込仕様（列名・必須項目・文字コード・見出し行の有無）は、各社の最新のヘルプで必ず確認する。仕様は変わることがあるので、ここに書いたものを正しいと決めつけない。

| このCSVの列 | freee会計（取引のインポートの例） | マネーフォワード クラウド会計（仕訳帳インポートの例） | 弥生会計（仕訳日記帳インポートの例） |
|-------------|-------------------------|-------------------------------|------------------------------|
| 日付 | 発生日 | 取引日 | 取引日付 |
| 取引先 | 取引先 | 借方取引先 など | 摘要に含める など |
| 摘要 | 備考 | 摘要 | 摘要 |
| 借方勘定科目 | 勘定科目（収支区分=支出） | 借方勘定科目 | 借方勘定科目 |
| 貸方勘定科目 | 決済口座 など | 貸方勘定科目 | 貸方勘定科目 |
| 金額(税込) | 金額 | 借方金額・貸方金額 | 借方金額・貸方金額 |
| 税区分 | 税区分 | 借方税区分 | 借方税区分 |
| インボイス登録番号 | 取引先の設定 など | 借方インボイス など | ソフトの版による |
| 形式チェック結果・要確認フラグ・要確認理由 | 取り込まない（確認用） | 取り込まない（確認用） | 取り込まない（確認用） |

- 税区分の名称は各ソフトで違う（例:「課税仕入10%」の表記）。ソフトの一覧に合わせて置き換える
- 文字コード（UTF-8／Shift_JIS）や見出し行の要否もソフトによって違う
- 取り込む前に、要確認の行をすべて人が確認・修正する
