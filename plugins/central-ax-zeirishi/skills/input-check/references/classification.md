# 情報の3区分・具体例・マスキング手順

事務所のAI利用規程がある場合は、そちらの区分・例を優先する。この表は規程が無い事務所が最初に使うための目安。

## 3区分の定義

| 区分 | 意味 | 扱い |
|------|------|------|
| 入力可 | 公開されている情報、顧問先が特定できない一般的な情報、マスキング済みの情報 | そのまま入力してよい |
| 条件付き | 顧問先が特定できる情報、顧問先の業務・財務の情報 | 事務所が承認したツール・プランで、学習利用オフ・DPA（データ処理契約）や利用規約の確認などを事務所が済ませている場合のみ入力する。確認できなければマスキングしてから入れる。必要な範囲に限る |
| 入力禁止 | 漏れたときの被害が大きく、法令で扱いが厳しく決まっている情報 | どのツール・プランでも入れない。伏字にしてから入れる |

## 具体例表

| 情報 | 区分 | メモ |
|------|------|------|
| 法令・通達・国税庁の公開情報、一般的な税務の質問 | 入力可 | 顧問先の固有情報を含めない書き方にする |
| 事務所の書式・テンプレート（顧問先情報なし） | 入力可 | |
| マスキング済みの資料（顧問先A・A社などに置き換え済み） | 入力可 | 業種・地域・規模の組み合わせで特定できないかも確認する |
| 顧問先の氏名・法人名・住所・電話番号・メールアドレス | 条件付き | 作業に不要なら伏せる |
| 決算書・試算表・総勘定元帳・売上や仕入の明細 | 条件付き | 必要な科目・期間だけに絞る |
| 取引先名・取引内容・契約書の内容 | 条件付き | 取引先も第三者。不要なら伏せる |
| 給与額・役員報酬・扶養親族の氏名 | 条件付き | 個人が特定できるので慎重に。不要なら伏せる |
| 面談の録音・文字起こし | 条件付き | 読み上げられた番号・病歴などが混ざりやすい。入力前に該当箇所を伏せる |
| マイナンバー（個人番号）、マイナンバーカードの写し | 入力禁止 | 源泉徴収票・扶養控除等申告書・給与支払報告書・支払調書などに載っていることが多い |
| 預金口座番号、クレジットカード番号 | 入力禁止 | 通帳コピー・振込依頼書・カード明細に注意 |
| パスワード・暗証番号・認証情報 | 入力禁止 | e-Taxの利用者識別番号と暗証番号、電子証明書のパスワード、会計ソフト・ネットバンキングのログイン情報など |
| 健康・病歴・障害の有無など要配慮個人情報 | 入力禁止 | 医療費控除の明細（病名・診療内容）、障害者控除の根拠資料、休職理由など |

上の表に無い情報は、「漏れたら顧問先が困るか」「法令で扱いが決まっているか」で考え、迷ったら入力せず税理士・責任者に確認する。

## マスキング（伏字化）の手順

1. 作業に不要な列・ページ・欄を先に削る（伏せるより消すほうが確実）
2. 残る情報を下の置き換えルールで伏せる
3. 氏名・法人名と仮名の対応表は、事務所内のAIに渡さない場所（事務所の共有フォルダ等）で管理する。AIには仮名だけを渡す
4. 伏せたあと、ファイル全体を見直して漏れが無いか確認する（ヘッダー・フッター・ファイル名・シート名・コメント欄にも残りやすい）

### 置き換えルール

| 元の情報 | 置き換え例 |
|----------|-----------|
| 顧問先の個人名 | 顧問先A、A氏 |
| 顧問先の法人名 | A社 |
| 取引先・関係者の名前 | B社、C氏（顧問先と重ならない記号にする） |
| 住所 | 市区町村まで、または「（住所）」 |
| 電話番号・メールアドレス | 「（電話）」「（メール）」 |
| マイナンバー・口座番号・カード番号 | すべて伏字（例: `************`、`支店名のみ・口座番号****`） |
| 生年月日 | 年代や年齢（計算に必要な場合だけ） |
| 金額 | 計算に必要なら残す。不要なら「（金額）」 |

### AIに伏字作業をさせない場面

入力禁止の情報を含む原本をAIに渡して「伏字にして」と頼むと、その時点で原本を入力したことになる。入力禁止の情報は、人が伏せてから渡す。条件付き区分の情報を伏せる作業をAIに頼むのは、事務所が承認したツール・プランの場合に限る。
