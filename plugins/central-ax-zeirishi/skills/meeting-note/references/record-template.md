# 面談記録の型

```markdown
# 面談記録 〈顧問先名（マスキング運用なら記号）〉

| 項目 | 内容 |
|------|------|
| 日時 | 〈YYYY-MM-DD HH:MM〜HH:MM〉 |
| 場所・方法 | 〈来所／訪問／オンライン／電話〉 |
| 出席者（顧問先） | 〈氏名・役職〉 |
| 出席者（事務所） | 〈氏名〉 |
| 記録者 | 〈氏名〉 |

## 論点

### 1. 〈論点の見出し（例: 役員報酬の改定）〉
- 顧問先の発言要旨: 〈何を相談・報告されたか〉
- 事務所の回答: 〈その場で回答した内容〉（その場で回答／持ち帰り）
- 根拠・資料: 〈示した資料、根拠にした条文・通達があれば〉

### 2. 〈論点の見出し〉
- 顧問先の発言要旨:
- 事務所の回答:
- 根拠・資料:

## 宿題

| # | 誰が | 何を | いつまで | 状態 |
|---|------|------|----------|------|
| 1 | 〈事務所: 担当者名〉 | 〈例: 〇〇の可否を調べて回答〉 | 〈YYYY-MM-DD／期限未定〉 | 未着手 |
| 2 | 〈顧問先: 氏名〉 | 〈例: 〇月分の請求書を送付〉 | 〈YYYY-MM-DD／期限未定〉 | 未着手 |

## 次回確認事項
- 〈次回の面談で確認すること〉
- 次回の予定: 〈YYYY-MM-DD／未定〉

## 記録者の確認事項（顧問先には共有しない）
- 未確認の項目: 〈メモに無く埋められなかった項目〉
- 要確認の発言: 〈不明瞭だった箇所、解釈が分かれる発言〉
- 税務判断を含む回答: 〈該当する論点番号〉 → tax-output-check で確認
```

## 書き方のポイント

- 発言要旨は、言った内容を短くまとめる。記録者の解釈を混ぜない
- 「事務所の回答」は、その場で答えたのか、持ち帰ったのかを必ず書く。持ち帰ったものは宿題にも載せる
- 金額・日付は、メモ・文字起こしにあるとおり書く。聞き間違いの可能性があれば要確認の発言に挙げる
- 雑談・本題と関係ない個人的な話は記録しない（病歴など要配慮個人情報や、家族の事情などの私的な話は特に書かない）
