# 回答文案の型と書き方

## 文面の型

```markdown
〈顧問先名〉 様

いつもお世話になっております。〈事務所名〉の〈担当者名〉です。
〈日付〉にいただいたご質問について、現時点でのご回答をお送りします。

## 結論
〈1〜3文で。事実次第で変わる場合は「〜の場合は〇〇、〜の場合は△△」と場合分けする〉

## 理由
〈なぜそうなるかを平易に。専門用語には一言説明を添える〉

根拠: 〈法令名 第〇条第〇項〉、〈通達名 〇-〇〉、〈国税庁タックスアンサー No.〇〇〇〇〉
〈確認できていない根拠は【根拠未確認】と付ける〉

## ご確認したい事項
正確にお答えするため、次の点を教えてください。
1. 〈例: 支出の時期（〇月〇日以前か以後か）〉
2. 〈例: 〇〇の届出を提出済みかどうか〉

## ご注意いただきたい点
- 〈期限、必要な書類、保存の要件など〉
- 上記はいただいた情報にもとづく現時点の回答です。事実関係が異なる場合は結論が変わることがあります。

ご不明な点がございましたら、お気軽にお問い合わせください。
```

## 事務所内向けメモ（文案とは分けて付ける）

```markdown
---
【事務所内メモ（顧問先には送らない）】
- 判断が分かれうる点:
- 検討した別の選択肢:
- 【根拠未確認】の箇所と確認方法:
- 税理士に確認してほしい点:
- 次の手順: tax-output-check → 税理士確認 → 送信（担当者）
```

## 書き方のポイント

- 結論を先に書く。顧問先は「できるか・いくらか・いつまでか」を最初に知りたい
- 断定してよいのは、前提事実がそろい、根拠を原典で確認できたときだけ。それ以外は「〜と考えられます」「〜の場合は」で書く
- 金額・期限・割合は根拠と突き合わせて書く。改正があった項目は、どの年度の取扱いかを明記する
- 一文を短くし、専門用語には一言の説明を添える
- 「必ず」「絶対」「問題ありません」は、根拠と事実がそろっていない限り使わない

## よくある「確認したい事項」

| 質問の種類 | 確認したいこと |
|------------|----------------|
| 経費になるか | 支出の目的、相手、日付、金額、事業との関係、私的利用の有無 |
| 消費税 | 課税事業者か、簡易課税か、取引先がインボイス登録事業者か、取引の時期 |
| 届出・申請 | 既に提出しているか、提出期限、対象の年度 |
| 給与・役員報酬 | 改定の時期、定期同額の要件との関係、議事録の有無 |
| 資産の購入 | 取得価額、取得日・使用開始日、中小企業者に当たるか |
| 個人の控除 | 対象者の続柄・所得、支出の時期、証明書類の有無 |
