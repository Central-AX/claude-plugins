# ③職員教育・誓約の記録 テンプレート

## 教育の記録（CSV）

```csv
実施日,対象者,区分（初回/定期/臨時）,内容,講師,理解度確認の方法と結果,誓約書の提出日,備考
```

| 列 | 書く内容 |
|----|---------|
| 実施日 | 教育を行った日 |
| 対象者 | 受講者の氏名（1行1名） |
| 区分 | 初回（利用開始前）／定期（年1回など）／臨時（規約変更・事故のあと） |
| 内容 | 扱った項目（例: 規程の説明、情報の3区分、マスキング、事故時の報告） |
| 講師 | 説明した人 |
| 理解度確認の方法と結果 | 確認テスト・口頭確認など、その結果 |
| 誓約書の提出日 | 誓約書を受け取った日 |

## 教育で扱う項目（最低限）

1. 事務所のAI・クラウド利用規程の要点
2. 使ってよいツール（ツール管理台帳）と、使ってはいけないツール
3. 入力する情報の3区分（入力可／条件付き／入力禁止）と具体例
4. マスキング（伏字化）のやり方
5. AIの出力は下書きであり、税理士が確認してから使うこと
6. 事故（誤入力・誤送信・アカウントの不正利用）が起きたときの報告先

## 誓約書の文例

```markdown
# AI・クラウドサービス利用に関する誓約書

〈事務所名〉 所長 〈氏名〉 殿

私は、〈事務所名〉AI・クラウドサービス利用規程の説明を受け、その内容を理解しました。次の事項を守ることを誓約します。

1. 業務では、ツール管理台帳で承認されたサービスだけを利用します。
2. 情報を入力する前に区分を確認し、入力禁止の情報（マイナンバー、預金口座番号・カード番号、パスワード・認証情報、健康・病歴など要配慮個人情報）は入力しません。
3. AIの出力を、税理士の確認を経ずに顧問先へ提出・送信しません。
4. 誤入力・誤送信などが起きた、または疑われるときは、直ちに責任者に報告します。
5. 退職後も、業務で知った顧問先の情報を漏らしません。

〈YYYY年MM月DD日〉
氏名　〈　　　　〉
```

誓約書の文言は、事務所の就業規則・既存の秘密保持誓約書と重複・矛盾しないよう事務所で調整する。
