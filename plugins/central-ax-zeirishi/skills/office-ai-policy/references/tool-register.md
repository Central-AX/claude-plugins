# ②ツール管理台帳 テンプレート

事務所で使うAI・クラウドサービスを1行1ツールで記録する。ユーザーが日税連の管理様式などを渡した場合は、その列構成を優先する。

## 列定義

| 列 | 書く内容 | 例 |
|----|---------|-----|
| 管理No | 連番 | 001 |
| ツール名 | サービス名 | 〈サービス名〉 |
| 種類 | 生成AI／AIエージェント／AI-OCR／議事録・文字起こし／クラウドストレージ／ブラウザ拡張 | 生成AI |
| 用途 | 何の業務に使うか | 顧問先への回答文案、面談記録の作成 |
| プラン | 契約プラン名、個人向けか法人向けか | 法人向けプラン |
| DPA/利用規約の確認 | データ処理契約・利用規約を確認したか、確認した版・日付 | 確認済（規約 〈YYYY-MM-DD〉版） |
| 学習利用設定 | 入力データが学習に使われるか、設定の状態 | オフ（管理画面で確認） |
| データ保存場所/リージョン | 保存される国・地域、保存期間 | 〈国・リージョン〉、〈保存期間〉 |
| 再委託先 | サービス提供者がさらに委託する事業者（公開されていれば） | 〈事業者名〉／公開なし |
| アクセス権限 | 利用者の範囲、管理者、共有設定 | 職員全員（個人アカウント）、管理者=所長 |
| 入力可能な区分（上限） | 入力可／条件付きまで | 条件付きまで |
| 承認者 | 利用を承認した人 | 〈所長名〉 |
| 確認日 | 上の項目を確認した日 | 〈YYYY-MM-DD〉 |
| 次回見直し日 | 次に確認する日（目安: 1年以内、規約変更時は随時） | 〈YYYY-MM-DD〉 |
| 備考 | 注意点、例外 | ブラウザ拡張はオフにして使う |

## CSVの見出し行

```csv
管理No,ツール名,種類,用途,プラン,DPA/利用規約の確認,学習利用設定,データ保存場所/リージョン,再委託先,アクセス権限,入力可能な区分（上限）,承認者,確認日,次回見直し日,備考
```

## 埋めるときの注意

- 学習利用設定・保存場所・再委託先は、プランや時期で変わる。推測で埋めず、ユーザーが設定画面・利用規約・提供元の公開資料で確認した内容を書く。確認できていない項目は「要確認（確認先: 〇〇）」と書く
- 同じサービスでも個人向けプランと法人向けプランで扱いが違うことが多い。プランごとに別の行にする
- 「入力可能な区分（上限）」を「条件付きまで」にするのは、学習利用オフとDPA/利用規約の確認が済んでいるツールに限る。どちらかが未確認なら「入力可のみ」にする
- 「入力禁止」区分の情報は、どのツールでも入力できない（列の選択肢に入れない）
